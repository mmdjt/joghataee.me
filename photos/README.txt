Drop your photos here with these exact filenames:

  me.jpg      — headshot on the homepage
  cat-1.jpg   — large cat photo
  cat-2.jpg   — second cat photo
  run.jpg     — running
  gym.jpg     — lifting / gym

JPG or PNG both work if you keep the same name and extension
(or change the src in index.html). Keep files under ~1 MB each
so the site stays fast.
