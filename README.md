# Personal website — first draft

Single-file static site: `index.html`.

Open it locally by double-clicking the file, or from a terminal:

```bash
# macOS
open index.html

# or serve it
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Domain + hosting (recommended path)

1. Register a `.me` domain (~$2–20 first year depending on registrar; renewal usually $15–20).
   Cheap options: Spaceship, NameSilo, Namecheap, Porkbun.
   Students: GitHub Student Pack → free `.me` for 1 year via Namecheap (`nc.me`).
2. Put this site on **GitHub Pages** (free) or **Cloudflare Pages** / **Netlify**.
3. Point the domain at the host (A/CNAME records). HTTPS is free.

I will give exact DNS records once you pick the host.
